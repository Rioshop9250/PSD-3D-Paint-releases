Windows 用 無料 3D ペイントアプリ

3D モデルに、そのまま描く。

PSD 3D Paint は、3D モデルの表面に直接ブラシで色を塗れるペイントアプリです。 Photoshop のようなレイヤー、PSD の読み書き、アニメーション作成、VRChat 用ロコモーション、 Unity Humanoid の .anim 書き出しまで、ひとつのアプリでこなせます。

無料ダウンロード 使い方を見る

Windows 10 / 11（64bit）・インストール不要のポータブル版あり・自動アップデート対応

Features

できること

テクスチャを描くための道具と、モデルを動かすための道具がそろっています。

🖌

3D に直接ペイント

ブラシ・鉛筆・エアブラシ・消しゴム・にじみ・クローンなど。UV の継ぎ目をまたいでも、そのまま塗れます。

🗂

レイヤーと PSD

グループ・マスク・クリッピング・調整レイヤー・16 種の描画モード。PSD の読み込みと書き出しに対応。

🧊

FBX / glTF / OBJ

複数メッシュ・マテリアルもそのまま。テクスチャは名前から自動で割り当て、透過テクスチャも表示。

🏃

アニメーション

コントローラーでポーズを付けてキーを打つだけ。歩き・走りなどのひな形からすぐ作れます。

🎮

VRChat・Unity

ロコモーション 19 種を一括作成。Humanoid のマッスル値 .anim で、別のアバターにもそのまま使えます。

🐍

Python プラグイン

.py を置くだけでフィルターメニューに追加。numpy で画素を加工したり、AO をベイクしたり。

Paint

3D と 2D を並べて、同じ絵を描く

3D ビューで塗った内容は、すぐ 2D（テクスチャ）ビューにも反映されます。細かい所は 2D で、形に沿った所は 3D で。どちらも同じレイヤー・同じ取り消し履歴を共有します。

  • グラデーションは 3D の位置で塗れるので、UV の島をまたいでもきれいにつながる
  • 凹凸（ノーマル）モードで、塗るだけで盛り上げ・彫り込み
  • AO・影・法線をテクスチャへベイク

Focus

見たいメッシュだけを表示して塗る

カーソルを合わせて / を押すと、そのメッシュだけを表示します（Blender と同じ操作）。Shift+H でパーツだけ、H でパーツを隠す。服の下や髪の内側など、ふだん見えない所も塗れます。

Animate

アニメーションも、このアプリで

ヒューマノイドのモデルなら、コントローラーの自動セットアップから始められます。待機・歩き・走り・手を振るなどのひな形を選んで、手直ししてキーを打つだけ。Ctrl+Z で 1 手ずつ戻せます。

  • VRChat ロコモーション 19 スロットをまとめて作成
  • Unity Humanoid（マッスル値）の .anim で書き出し

Get started

3 ステップではじめる

ダウンロードして起動

インストーラー版をダブルクリック。ポータブル版ならそのまま起動できます。

3D モデルを開く

スタート画面の「3D モデルを開く」から .fbx / .glb などを選択。テクスチャも自動で取り込めます。

モデルの上で塗る

ブラシ（B）を選んで、モデルの表面をドラッグ。完成したら PSD や PNG で書き出します。

Updates

更新は自動で

新しいバージョンが出ると、起動時に「更新しますか？」と聞いてくれます。「更新する」→「再起動して更新」を押すだけ。アンインストールや再ダウンロードは要りません。

さっそく塗ってみよう

無料で使えます。モデルが無くても、形状メニューの球や箱で試せます。
