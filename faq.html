よくある質問

解決しないときは GitHub の Issues で知らせてください。

インストール・起動

「Windows によって PC が保護されました」と出て起動できない

コード署名をしていないため、Windows SmartScreen の警告が出ます。［詳細情報］→［実行］ で起動できます。

インストーラー版とポータブル版、どちらを選べばいい？

迷ったら インストーラー版。スタートメニューに登録され、更新も終了時に自動で適用されます。USB メモリで持ち歩きたい、インストールしたくない場合はポータブル版を選んでください。どちらも自動アップデートに対応しています。

無料ですか？

無料です。

Mac や Linux で使えますか？

いまは Windows 10 / 11（64bit）用だけです。

アップデート

新しいバージョンにするには、アンインストールして入れ直す必要がありますか？

いいえ。起動時に新しいバージョンがあると「更新しますか？」と表示されるので、更新する → 再起動して更新 を押すだけです。いまのバージョンは ヘルプ ＞ バージョン情報… で確認できます。

自動で更新を確認してほしくない

ヘルプ ＞ 起動時に自動で更新を確認 のチェックを外してください。ヘルプ ＞ 更新を確認… でいつでも手動で確認できます。

3D モデル

どんなファイルを開けますか？

FBX / glTF・GLB / VRM / OBJ / STL / PLY です。STL と PLY は UV を持たないので表示だけで、塗れません。.gltf は外部ファイル（.bin や画像）を参照していると読めないので、.glb で書き出してください。

モデルは開けたけど、テクスチャが付いていない

モデルと同じフォルダー（または FBX フォルダーの親）にテクスチャ画像があれば、開いたときに割り当て画面が出ます。出なかった場合や選び直したい場合は ファイル ＞ モデルのテクスチャを取り込む を使ってください。詳しくはこちら。

「UV が無い」と言われて塗れない

UV 展開されていないメッシュは塗れません。Blender などで UV 展開してから .glb / .fbx で書き出してください。

モデルが見当たらない・位置がずれている

テンキーの . で全体を表示します。読み込み時に中心を原点に合わせ、底面がグリッドに乗るように自動で配置しています。

髪の毛先やまつ毛が透けずに四角く見える

マテリアルパネルの 透過 を「切り抜き」にしてみてください。既定の「自動」は、透明な画素があれば透かします。透過マスク（白 = 見える、黒 = 透明）を使うモデルは、テクスチャの取り込み画面でマスク画像も選んでください。

服の下や髪の内側が塗れない

塗りたいメッシュにカーソルを合わせて /（そのメッシュだけ表示）や Shift+H（そのパーツだけ表示）を押してください。隠した部分は塗りの対象から外れます。詳しくはこちら。

表情（シェイプキー）が読み込まれない

読み込みを速くするため、シェイプキーは既定で読み込みません。環境設定 ＞ 一般 で読み込むようにできます。

動作・表示

ノートパソコンだと重い

右下の 表示: 自動 を押して 軽量 にしてください。視点を動かしている間や塗っている間だけ解像度を下げ、影と選択枠を省略します。それでも重いときは、キャンバスの解像度を下げる、環境設定で元に戻す段数を減らす、影を切る、を試してください。

パネルの配置がぐちゃぐちゃになった

ウィンドウ ＞ このワークスペースの配置をリセット で元に戻ります。右上の レイアウト ▾ からプリセットも選べます。

ショートカットが効かない

文字入力欄にカーソルがあると、キーは入力欄に入ります。3D ビューを一度クリックしてから押してください。キーの割り当ては 環境設定 ＞ ショートカット で確認・変更できます。

設定を初期化したい

アプリを終了して %APPDATA%\PSD 3D Paint\ を削除してください。保存したプロジェクト（.p3dp）は別の場所にあるので消えません。

アニメーション・VRChat・Unity

書き出した .anim を別のアバターでも使えますか？

ヒューマノイド（マッスル） 形式で書き出した .anim は、Rig が Humanoid のアバターならどれにでも使えます。このモデル専用 形式は、書き出したモデルにだけ使えます。

VRChat のロコモーションを差し替えたい

アニメーションモードの VRC ロコモーション タブで 19 スロットを作り、VRChat 用に書き出し… で Unity プロジェクトの Assets を選びます。Unity で Tools ＞ PSD 3D Paint ＞ VRC ロコモーションを作成 を実行すると、Animator Controller まで作られます。詳しくはこちら。

間違えてキーを消した

アニメーションモードでも Ctrl+Z で戻せます（キーの追加・削除・移動、ポーズの変更など。最大 100 手）。

プラグイン

プラグインが動かない・メニューに出ない

Python 3 が必要です。環境設定 ＞ プラグイン に Python のバージョンが表示されているか確認し、見つからないときは Python設定 で場所を指定してください。numpy を使うプラグインは pip install numpy も必要です。エラーは Python コンソールパネルに出ます。

自分でプラグインを作りたい

プラグインの作り方 を見てください。.py を 1 つ書くだけで作れます。
