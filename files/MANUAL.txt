# PSD 3D Paint — 説明書（マニュアル）

3D モデルにテクスチャを直接ペイントするデスクトップアプリです。Blender ふうの視点操作、
GIMP ふうの UI、Clip Studio / Photoshop ふうのレイヤー、PSD の読み書き、凹凸（ノーマルマップ）
ペイント、ライト / AO / 影 / 法線のベイク、Python プラグインに対応しています。

- 対応 OS: Windows 10 / 11（64bit）
- インストーラー版とポータブル版（インストール不要の単一ファイル）。どちらも自動アップデート対応
- 本体は Electron + three.js。テクスチャ編集は Canvas2D、PSD は `ag-psd`。

## 1. 入手と起動

### ダウンロード

このリポジトリの **Releases** ページから、インストーラー版 `PSD-3D-Paint-Setup-<バージョン>.exe`（おすすめ）か
ポータブル版 `PSD-3D-Paint-<バージョン>-portable.exe` をダウンロードします。

### 起動

ダウンロードした `.exe` を**ダブルクリック**するだけです。インストーラーは動きません。単一ファイルなので、
USB メモリや任意のフォルダーへコピーしても動きます。

- 初回起動は自己展開のため数秒かかることがあります。
- Windows SmartScreen が「WindowsによってPCが保護されました」と表示する場合があります
  （署名なしのため）。**［詳細情報］→［実行］** で起動できます。心配な場合は配布元に確認してください。
- 設定や「最近開いたファイル」の履歴は Windows のユーザーデータフォルダーに保存されます
  （`%APPDATA%\PSD 3D Paint\`）。アプリ本体を消しても残ります。

### ソースから動かす場合（開発者向け）

```bash
npm install
npm start
```

Node.js が必要です。`npm run dist:portable` で単一 exe を、`npm run dist` でフォルダー版をビルドできます。

## 2. 画面の見かた

**どこへでも移動（Unity 風）**: パネル・タブ・**ツール列** は、左・右・**下**のドック、浮動ウィンドウへ自由に移せます。
浮動ウィンドウの中にもタブを集められ、ウィンドウのタイトルバーをドックの上へドラッグすると中身ごとドッキングします。
ツール列は左端の点々（つまみ）をドラッグして移動でき、横長の場所では並んだ表示になります。
ドラッグ中は空いているドックが点線の受け皿として表示されます。下のドックは境目のドラッグで高さを変えられます。
左ドックは「カラー｜ツール設定｜ブラシ効果｜対称ペイント」のタブに分かれています（使わないツールでは「このツールでは使いません」と表示）。

**レイアウト**: 右上の「レイアウト ▾」（または ウィンドウ ＞ レイアウト）で、
プリセット（標準／ワイド（下に並べる）／コンパクト（右に 1 列）／左にまとめる／ツールを浮動ウィンドウに）を選べます。
「現在のレイアウトを保存…」で名前を付けて保存し、同じメニューから呼び出し・× で削除できます（ワークスペースごと）。
「レイアウトを書き出し / 読み込み」で JSON ファイルにして別の PC へ持っていけます。「初期レイアウトに戻す」で元通りです。

**タブの移動**: タブの見出しをドラッグすると、同じ帯の中で **並べ替え**、別のタブ帯の好きな位置へ **移動**、
パネル見出しへ重ねて **新しいタブ化**、ビューの上で離すと **浮動ウィンドウ** になります。タブ帯の空いている所を
ドラッグすると **タブのグループごと** 別のドックや別のグループへ移せます。

**一部だけ表示（Blender 風）**: 3D ビューで対象にカーソルを合わせて
**/**（テンキーの / も可）= そのメッシュだけ表示、**Shift+H** = そのパーツだけ表示（どちらももう一度押すと戻る）、
**H** = そのパーツを隠す、**Alt+H** = すべて表示。ショートカットを使わなくても、3D ビュー左上の
「メッシュだけ／パーツだけ／パーツを隠す／すべて表示」ボタンを押してからモデルをクリックすれば同じことができます。
隠した部分は塗りの対象から外れるので、服の下など見えなかった所も塗れます。

**タブで切り替え（Unity 風）**: パネルはタブにまとまっています（例: 右上「レイヤー｜マテリアル｜チャンネル」、
その下「ライト｜クイック調整｜ベイク設定｜凹凸ペイント」、「アウトライナー｜Python」。アニメーションでは
「ポーズ｜キーフレーム｜クリップ」「アニメーション ツール｜VRC ロコモーション」）。タブの見出しをドラッグすれば
別の場所へ移動・別のタブへ合体・浮動ウィンドウ化でき、「ウィンドウ ＞ レイアウトを初期化」で戻せます。
中央は **3D ビュー｜2D（テクスチャ）｜並べて表示** のタブで切り替え、左のツール列は上の
**描画｜補正｜選択｜全部** のタブでツールの種類を切り替えます（ショートカットで別の種類のツールを選ぶと自動でそのタブに切り替わります）。

```
┌─────────────────────────────────────────────────────────────┐
│ メニューバー   ファイル 編集 レイヤー 形状 ベイク フィルター 表示 ヘルプ  [🎨/🔵]│
├───────┬─────────────────────────────────────┬───────────────┤
│ツール  │                                     │ 右ドック       │
│ボックス│         3D ビューポート              │ ・クイック調整 │
│       │      （モデルをここで塗る）           │ ・レイヤー     │
│ツール  │                                     │ ・チャンネル   │
│オプ   │                                     │ ・オブジェクト │
│ション │─────────────────────────────────────│ ・マテリアル   │
│       │  2D ビュー（テクスチャを平面で編集） │ ・凹凸ペイント │
│       │                                     │ ・ライト       │
│描画色 │                                     │ ・ベイク設定   │
│背景色 │                                     │ ・アニメ       │
├───────┴─────────────────────────────────────┴───────────────┤
│ ステータスバー（操作の結果・ヒントが出ます）                     │
└─────────────────────────────────────────────────────────────┘
```

- **メニューバー**: すべての機能の入口。右端の**モードチップ**をクリックすると
  **カラー → 法線（凹凸）→ 選択** と循環します（`Tab` はカラー ⇔ 法線）。
  **選択モード**では 3D モデルをクリックするだけでメッシュを選択でき、ペイントは無効です（ビューの縁がアンバー色）。
- **ツールボックス**: アイコングリッド。選んだツールに応じて下の**ツールオプション**の項目が変わります。
- **描画色 / 背景色スウォッチ**: `X` で入れ替え、`D` で初期化（黒／白）。
- **右ドック**: 折りたたみ式パネル群。見出しをクリックで開閉。
- **2D ビュー**: テクスチャを平面で見て、直接ペイント・変形・グラデーション・テキストなどを行います。
  3D と同じレイヤー・ヒストリを共有します。
- **スタート画面**: 起動直後は白紙を作らず、スタート画面（新規／画像／PSD／3D モデル／最近開いたファイル）を表示します。
  `×` で閉じるか、**ファイル → スタート画面…**でいつでも再表示。
- **ステータスバー左端**に、いま描き込まれる先（カラー／法線、どのレイヤー）を常時表示します。
  法線（凹凸）モード中は 3D・2D ビューの縁が青く、選択モード中はアンバー色になります。

### マルチウィンドウ・タブ

メニューバーの一番上、タブストリップで複数のドキュメントを同時に開けます。

- **新しいタブ**（`Ctrl+Shift+T`、またはタブストリップ右端の **＋**、ファイル → 新しいタブ）:
  同じウィンドウの中にもう1つ、独立したドキュメントのタブを追加します。
- **新しいウィンドウ**（`Ctrl+Shift+N`、またはタブストリップ右端の **⧉**、ファイル → 新しいウィンドウ）:
  別のウィンドウを開き、そちらにもタブが1つ入った状態で始まります。
- 各タブは**レイヤー・3D シーン・法線マップ・ヒストリ・選択範囲が完全に独立**しています。片方のタブで
  何をしても、他のタブ・ウィンドウには一切影響しません（環境設定やキー割当などの**設定だけは共有**）。
- タブに**未保存の変更があると見出しの左に ● が付きます**。●が付いたタブを閉じよう（× をクリック /
  `Ctrl+Shift+W`）とすると確認ダイアログが出ます（保存して閉じる／保存せずに閉じる／キャンセル）。
  ウィンドウを閉じるときも、中の全タブをまとめて同じように確認します。
- `Ctrl+PageDown` で次のタブへ、`Ctrl+PageUp` で前のタブへ切り替えます（`Ctrl+Tab` はモード切替のパイメニューです）。
- タブを閉じて 0 個になると、自動的に新しい空のタブが1つ開きます（アプリを常に何かしらのドキュメントが
  開いた状態に保つため）。

### ドラッグ＆ドロップで読み込み

**画像・3D モデル（fbx/obj/gltf/glb/stl/ply）・PSD・プロジェクト（`.p3dp`）**は、ファイルをウィンドウの
どこにドラッグ＆ドロップしても読み込めます。ドロップ中は「ここにドロップして読み込む」という案内が
表示されます。最近使ったファイルを開くのと同じ経路を通るので、メニューから開いたときと動作は完全に
同じです（画像は新規レイヤーとして追加、モデルは開く、PSD/プロジェクトはそのまま開きます）。
複数ファイルを一度にドロップすると、順番に処理されます。

## 3. 3D ビューの操作

Blender に合わせています（マウス＋テンキー）。

| 操作 | 割り当て |
| --- | --- |
| 回転（オービット） | 中ボタンドラッグ |
| 平行移動（パン） | Shift + 中ボタンドラッグ |
| ズーム | ホイール、または Ctrl + 中ボタンドラッグ |
| 正面 / 右 / 上 | テンキー 1 / 3 / 7（Shift で反対側） |
| 透視 ⇔ 平行投影 | テンキー 5 |
| 全体を表示（フレーム） | テンキー `.` |
| 選択物を隠す / すべて表示 / 単独表示 | `H` / `Alt+H` / `/` |

- 読み込んだモデルは**自動でスケール正規化**され、**X/Z は中心、Y はモデルの底面がグリッド（原点の高さ）に接する**ように配置されます（原点より下に埋まりません）。Z-up 切替時も再配置されます。
- **表示 → 表示モード**で見え方を切り替えられます。
  - **レンダリング**（既定）: ライト・影ありの PBR
  - **トゥーン**: セル調（明暗を数段に量子化）
  - **影なし（フラット / アンリット）**: ライティングを無視してテクスチャの色そのものを表示。影も落ちません。テクスチャの確認に便利
- **表示 → シェーディング**でソリッド／ソリッド+ワイヤー／ワイヤーフレームを切り替え（`Shift+Z` で巡回）。表示モードとは独立して重ねられます。

## 4. クイックスタート

1. アプリを起動 → スタート画面で **「3D モデルを開く」** を選び、`.glb` / `.fbx` / `.obj` などを開きます。
   （モデルが無くても、**形状メニュー**の球・箱などのプリミティブで試せます）
2. UV があるメッシュが自動でペイント対象になります。テクスチャが無ければ**新規テクスチャ**（解像度を指定）で作成、
   または PSD / 画像を読み込みます。
3. 右ドックの**レイヤー**パネルで新規レイヤーを追加します（用紙レイヤーの上で作業）。
4. ツールボックスで**ブラシ (B)** を選び、描画色スウォッチで色を決めて、**モデルの表面を直接ドラッグ**して塗ります。
   2D ビューで塗っても同じです。
5. こまめに **ファイル → プロジェクトを上書き保存（Ctrl+S）** で `.p3dp` に保存します。
6. 完成したら **ファイル → PSD を書き出す（Ctrl+E）** か PNG などで書き出します。

## 5. 3D モデルの読み込み

**ファイル → 3D モデルを開く**（または高ポリモデルを開く）。

### 対応形式

`FBX` / `OBJ` / `glTF` / `GLB` / `STL` / `PLY`（拡張子で自動判定）。

- **glTF は自己完結ファイルか `.glb` 推奨**。`.gltf` は別ファイル（`.bin`・テクスチャ）を同梱できないため、
  外部参照があると読み込めません。
- **Draco / Meshopt 圧縮**の glTF・GLB に対応（デコーダーを同梱・自動セットアップ）。
- STL / PLY は UV を持たないためペイント・ベイク対象外（表示のみ）。
- glTF / FBX の**元マテリアル・テクスチャはペイント用マテリアルに置き換わります**。

### 複数メッシュ・オブジェクト

複数のメッシュをそのまま扱います。UV があるものを個別にペイント対象化し、右ドックの
**オブジェクト（3D 選択ビュー）**パネルにシーングラフをツリー表示します。行クリックで選択、
選択モードや 3D ビューのダブルクリックでもそのオブジェクトを選択できます。各行で表示切替・単独表示・
**ペイントを 1 メッシュに限定**ができます。

**「選択メッシュの UV だけ表示」**（既定 ON・設定を保持）にすると、2D ビューに重ねる UV 線は
選択中のメッシュの分だけになります（何も選択していないときだけ全メッシュを表示）。
複数メッシュのモデルで目当てのメッシュの UV を見やすくするための既定です。

### 非対応オブジェクトの扱い

カメラ・ライト・ジオメトリの無いメッシュ・読み込みに失敗したノードは、**小さな 3 軸ギズモの「空オブジェクト」**
として名前とトランスフォームを保ったまま配置され、対応部分だけが読み込まれます
（アウトライナーには「（空・カメラ）」等とグレー斜体で表示）。

### FBX のアニメーション不具合

壊れたアニメーションカーブがある FBX（`Cannot read properties of undefined (reading 'curves')`）は、
**アニメーションを捨ててジオメトリだけ**読み込みます。

### ハイポリ

250 万三角形まで高速レイキャスト用の BVH を構築します（超過はブルートフォース）。
高ポリ → 低ポリの法線ベイクは**ベイク設定**パネルから。

## 6. ツール（カラー）

ツールボックスから選択。かっこ内はショートカット。

| ツール | 説明 |
| --- | --- |
| ブラシ (B) | やわらかい円ブラシ。硬さ・不透明度・流量・間隔などを設定。 |
| 鉛筆 (N) | アンチエイリアスなしの硬いブラシ。 |
| エアブラシ (A) | 押しっぱなしで濃くなる吹き付け。 |
| 消しゴム (E) | 透明に消す（レイヤーマスク上では隠す）。 |
| 指先 (S) | 下の色を引きずって伸ばす。 |
| ぼかし (R) | なぞった部分をぼかす。 |
| 塗りつぶし (G) | 許容値内の連続領域を塗る。選択範囲内のみ。 |
| テクスチャブラシ (T) | パターン画像を「覆い」として色をスタンプ。継ぎ目が合うようキャンバス空間に固定。組み込みパターン 14 種（水玉 / グリッド / ハッチング / クロスハッチ / 斜線 / スパッタ / 点描 / チョーク / うろこ / 織り / 砂 / ノイズ / キャンバス地 / レンガ）＋画像読み込み。**「＋ プリセット保存」**で今の設定に名前を付けて保存、下のスウォッチをクリックで即呼び出し（右クリックで削除）。**「プリセットを書き出し… / 読み込み…」**で `texture-presets.json` としてやり取りできます。 |
| クローン (K) | **Alt+クリック**でソース指定 → そのオフセットで複写。 |
| 修復 (J) | クローンと同じだが、パッチの平均色を塗り先に合わせてから複写（質感だけ転写）。 |
| 覆い焼き (O) / 焼き込み (Shift+O) | なぞった部分を明るく／暗く。 |
| グラデーション (Shift+G) | **3D（モデル上）**: 3D ビューでモデルの上を始点→終点へドラッグすると、表面の **3D 位置**で色が決まります（UV の継ぎ目や島をまたいでもきれいにつながり、モデルに吹き付けたように塗れます）。形は 線形／球（放射）／反射／円柱。**2D（テクスチャ）**: 2D ビューまたはモデル上のドラッグをテクスチャ平面で塗ります。形は 線形／放射／反射／角度／ひし形。どちらも「繰り返し」でしま模様。色はカスタム多段／描画色→背景色／描画色→透明。選択範囲があればその中だけ。3D/2D はツール設定の切替ボタンで選びます。 |
| テキスト (Y) | **2D ビュー・3D モデルどちらもクリック** → ダイアログ → **編集可能なテキストレイヤー**。レイヤーの ✎ ／ダブルクリックで再編集。 |
| パス (P) | **2D ビュー・3D モデルどちらもクリックで頂点を追加**（3D では表面に沿ってオレンジのラインでライブプレビュー）。Enter か素早い2回目のクリックで確定、Esc で取消。**編集可能なパス／シェイプレイヤー**。 |
| スポイト (I) | 表面の色を描画色に取得。 |
| 変形 (Ctrl+T) | アクティブレイヤーを浮かせて拡縮・回転・移動。オプションで「遠近・自由歪み」（4 隅ドラッグ）。Enter 確定／Esc 取消。 |
| 矩形 (M) / 楕円 / なげなわ (L) / ファジー選択 (U) | [選択範囲](#10-選択範囲)を参照。 |

- **ストローク開始点から最初のポインタ移動までを補間**するので、速い描き出しでも点線になりません。
- **Shift+クリック**で直前のストローク終点から直線（連続クリックで折れ線）。カラー・凹凸・マスク・2D/3D すべてで有効。
- `[` `]` でブラシサイズを増減。

## 7. ブラシの設定

ツールオプション（ツールボックスの下）で調整します。多くの項目はカラーと凹凸で**共有**されます。

- **サイズ / 硬さ / 不透明度 / 流量 / 間隔**
- **筆圧**: サイズに効かせる／不透明度に効かせる（ペンタブ対応。0..1 を読み取り）
- **ジッター**: 位置（散布）・サイズ・角度・色相・彩度/明度をランダムに揺らす
- **形状**: 丸み（→細い楕円）・角度
- **フェードイン**: 描き出しから一定距離でサイズ・不透明度を立ち上げる
- **放射対称**: キャンバス中心まわりに N 回複製
- **ミラー**: 2D X/Y（テクスチャ空間の反転）・3D 軸（反射レイでの対称ペイント）
- **ストロークのブレンドモード**: 仕上がりストロークをレイヤーに合成する方法

## 8. 凹凸（ノーマル）モード

メニューバー右の**モードチップ**、または **`Tab`** でカラー ⇔ 法線（凹凸）を切り替えます。
高ポリ化やベイクは不要で、塗るだけで凹凸が付きます（内部は高さバッファ → Sobel でタンジェント法線化 →
`material.normalMap`。塗った周辺だけを部分再計算するので 4K でもリアルタイム）。

### カラーと同じツールがそのまま効きます（機能パリティ）

| ツール | 凹凸モードでの動作 |
| --- | --- |
| ブラシ / 鉛筆 / エアブラシ | 盛り上げ（凸）／彫り込み（凹）／ならす／ざらつき（モードで切替） |
| 消しゴム | 凹凸を消して**平ら（基準の高さ）に戻す** |
| 指先 | relief を引きずる（スカルプトの move） |
| ぼかし | 局所的になめらかに（スカルプトの smooth） |
| クローン / 修復 | Alt でソース指定 → レリーフをスタンプ（修復は周囲の高さに馴染ませる） |
| テクスチャブラシ | 模様の輝度を凹凸として刻む（布・木目・叩き目） |
| 覆い焼き / 焼き込み | 持ち上げ／へこませ |
| 塗りつぶし | 連続領域（＋選択範囲）を一段のプラトー（台地／窪み）に |
| スポイト | その点の高さを % で取得 |

### 凹凸パネルの設定

- **モード**: 盛り上げ（凸）／彫り込み（凹）／ならす／ざらつき
- **合成**: ふつう ／ **盛り上げのみ**（下げない）／ **彫り込みのみ**（上げない）
- **凸凹の強さ（-1〜+1 の符号付き）**: ＋で凸、－で凹（モードと双方向同期）
- **ブラシサイズ / ふちのぼかし / 塗りの濃さ**（カラーブラシと共有）
- **凹凸の強さ（全体）**: 法線マップの効き
- **下地のなめらかさ / 全体を平滑化 / 全消去**
- **法線 PNG 書き出し**

選択範囲・ミラー・直線（Shift）も凹凸で有効です。
※ グラデーション／テキスト／パスの凹凸化は今後対応予定。

## 9. レイヤー

右ドックの**レイヤー**パネル。非破壊で、追加 / 複製 / 下に結合 / 削除 / 並べ替え / 表示切替 / 名前変更 /
不透明度 / 16 ブレンドモードに対応します。

- **グループ（フォルダ）**: レイヤーをまとめる。アイソレート合成（パススルーは未対応）。
- **レイヤーマスク**: 白＝表示 / 黒＝隠す。ブラシで直接描けます。
- **クリッピング**: 下のレイヤーの不透明部分だけに適用。
- **調整レイヤー**: 明るさ・コントラスト / 色相・彩度 / トーンカーブ（5 制御点スプライン）/
  カラーバランス / グレースケール / 反転 / セピア / レベル補正 / ポスタリゼーション / 2 階調化。
  マスク・クリップと併用可。
- **元に戻す / やり直し**: `Ctrl+Z` / `Ctrl+Shift+Z`。ペイント操作（レイヤー / マスク / 法線高さ）のストローク単位。
  既定 30 ステップ（環境設定で 8〜120）。ヒストリは触れた矩形だけを保持し、スタック全体を
  約 600 MB のメモリ予算で管理するので、長時間セッションでも重くなりません。

PSD 読み込み時はグループ・クリッピング・マスクを取り込みます（調整レイヤーはスキップ）。

### 右クリックメニュー

レイヤーの行を**右クリック**すると、名前変更 / 複製 / 下に結合 / グループ化・解除 /
マスク追加・削除 / クリッピング / **このレイヤーだけ表示** / すべて表示 /
**メッシュにひも付け**（サブメニュー）/ **調整レイヤーを追加**（サブメニュー）/ 削除
をまとめて呼び出せます。`Esc` かメニュー外クリックで閉じます。
サブメニューは開こうとした側（既定は左）にスペースが足りないと自動で反対側に開き、縦位置も
画面内に収まるよう調整されるので、画面の端でメニューを開いても項目が見切れることはありません。

### メッシュごとにレイヤーを分ける

オブジェクトパネルの **「メッシュごとにレイヤーを分ける（3D で塗ると自動）」**を ON にすると、
3D モデルのメッシュを塗った瞬間に、そのメッシュ専用のレイヤーグループ（＋ペイントレイヤー）が
自動で作られてひも付き、以降そのメッシュを塗ると自動でそのグループに切り替わります。
複数メッシュのモデルで「すべてのメッシュが同じレイヤーになってしまう」のを防ぎます。
OFF にすると従来どおり単一の共有レイヤーに塗ります。

### レイヤーとメッシュのひも付け

レイヤーパネルの各行にある **🔗 アイコン**をクリックすると、そのレイヤー（特にグループ）を
特定の 3D メッシュに割り当てられます。ひも付けると:

- **グループをひも付けると、そのメッシュのマテリアルの「テクスチャ元」が自動でそのグループに設定されます**
  （＝そのグループを塗ればそのメッシュに反映される）。
- **3D ビュー・オブジェクトパネルでそのメッシュを選ぶと、レイヤーパネルが自動でそのグループへジャンプ**します。
  今どのグループがどのメッシュ用なのかを探し回らずに済みます。
- **ひも付いたグループは見た目でも分かります**（GIMP 風）: レイヤーパネルで、ただのフォルダアイコンの
  代わりに**実際に合成された画像のサムネイル**が表示され、行に緑のアクセント（左枠線・背景の強調）と
  **「→ メッシュ名」のバッジ**が付きます。ひも付け先を探す・確認するのに 🔗 アイコンをクリックする
  必要がありません。

複数メッシュのモデルでパーツごとに塗り分けたいとき（「肌」「服」「金具」など）に使います。
右ドックの**マテリアル**パネルの **「＋ このメッシュ用のレイヤーグループを新規作成してひも付け」**
ボタンなら、グループ作成・ひも付け・テクスチャ元の設定を1クリックでまとめて行えます。ひも付けは
プロジェクトに保存されます。

## 10. 選択範囲

左ツール列から **矩形 (M) / 楕円 / なげなわ (L) / ファジー選択（自動選択, U）**。2D ビューでドラッグして作成します。

- **Shift＝追加 / Alt＝削除 / Shift+Alt＝交差**
- ファジー選択は許容値スライダー付き。
- **選択メニュー**: すべて選択 (Ctrl+A) / 解除 (Ctrl+D) / 反転 (Ctrl+I) / **コピー (Ctrl+C) / 切り取り (Ctrl+X) /
  貼り付け (Ctrl+V)** / **塗りつぶし（描画色／背景色）** / 境界をぼかす… / 拡大… / 縮小… /
  輝度・アルファを選択範囲に読み込み
- 保護された領域は**暗く表示＋マーチングアンツ**（破線アニメ）。
- 選択中は**ブラシ・消しゴム・テクスチャ・塗りつぶし・にじみ・ぼかし・フィルター・クイック調整・凹凸ペイント**が
  すべて選択範囲内だけに適用されます（3D モデルへのペイントも同じテクスチャ空間マスクで制限）。

### コピー・切り取り・貼り付け・塗りつぶし

- **コピー（`Ctrl+C`）／切り取り（`Ctrl+X`）**: アクティブレイヤーのうち選択範囲の**形どおり**の部分を
  抜き出します（矩形選択でも、選択範囲の外側は透明のまま保持されるので、丸や自由形の選択でも余計な
  背景は付きません）。選択範囲が無いときはレイヤー全体をコピー／切り取りします。切り取りは取り消し可能です。
- **貼り付け（`Ctrl+V`）**: 直前にコピー／切り取りした内容を**元あった位置に新規レイヤー**として貼り付けます。
  貼り付けた直後は選択範囲がその貼り付けた範囲に切り替わるので、そのまま移動・変形ツールで動かせます。
- **塗りつぶし（描画色／背景色）**: 選択範囲（無ければレイヤー全体）を描画色スウォッチ／背景色スウォッチで
  塗りつぶします。取り消し可能です。
- **2D ビューで選択範囲の内側を右クリック**すると、上記に加えフェザー・拡大・縮小・反転・解除もまとめた
  専用の右クリックメニューが出ます（選択範囲の**外側**での右クリックは、従来どおり一時スポイトとして動作します）。

### クイックマスク

**`Q`** または選択メニューで切替。選択範囲を半透明の赤ウォッシュで表示し、**ブラシで塗ると広がり・消しゴムで削れます**。
`Q` で戻すとマスクが選択範囲に確定します。

## 11. 色調補正・フィルター・模様生成

### フィルターメニュー（52 種）

ぼかし（ガウス／モーション／モザイク／ズーム）、強調（シャープ／アンシャープマスク）、
輪郭（Sobel／エンボス／ラプラシアン）、変形（渦巻き・つまむ／波紋／球面化／極座標／波／ずらし／鏡面タイル）、
ノイズ（RGB／ごま塩／ばらまき）、
色（反転／明るさ・コントラスト／色相・彩度／トーンカーブ／カラーバランス／覆い焼き・焼き込み（全体）／
レベル補正／ガンマ／色温度／脱色／グラデーションマップ／デュオトーン／色収差／ビネット）、

- アクティブレイヤー（またはマスク）に適用、取り消し可。
- **`Ctrl+F` で直前のフィルターを繰り返し**。

### クイック調整・生成パネル

### 模様・テクスチャ生成（フィルター → 描画）

**ボロノイ**（フラットなセル＋境界線、色＝ランダム／FG→BG／グレースケール／FG のみ、境界線の太さ・色、
ばらつき、シード指定。3×3 グリッド探索でタイル継ぎ目なし）／市松／格子／水玉／レンガ／ストライプ。
**「新規レイヤーに描画」**チェックで別レイヤーに生成できます。

## 12. チャンネル / アルファロック / ソフトプルーフ / インデックス

- **チャンネル**パネル: 👁 で R / G / B / アルファの 1 チャンネルだけを 2D ビューに表示。
  「→選択」でそのチャンネルの値を選択範囲に読み込み。
- **透明部分を保護（アルファロック）**: アクティブレイヤーの既存アルファの外に描かない。
- **表示 → CMYK ソフトプルーフ**: RGB→CMYK→RGB を往復して印刷の見えを画面で近似
  （ICC は未使用の近似。編集・書き出しは RGB のまま）。
- **表示 / フィルター → 色 → インデックスカラー（減色）**: メディアンカットで 2〜256 色パレット＋
  Floyd–Steinberg 誤差拡散ディザ（任意）。

## 13. マテリアル

右ドックの**マテリアル**パネル。メッシュを選ぶ（選択モードで 3D モデルをクリック、
オブジェクトパネルで選択、または 3D ビューをダブルクリック）と表示され、
選択中メッシュの以下を即時に編集できます。

- **テクスチャ画像スロット**（パネル冒頭・Blender 風）: 現在このメッシュに表示されている画像の
  プレビューサムネイル、**テクスチャ元グループの選択**、**「🎨 このメッシュを描く」**、**「＋ 新規」**、
  **「🖼 画像を読み込む…」** をひとまとめにしたブロックです。
  - **「🎨 このメッシュを描く」**: このメッシュ専用のレイヤーグループ（＋ペイントレイヤー）が無ければ用意し、
    そのレイヤーを選択してカラーモードに戻します。押したらすぐ塗り始められます。
  - **「＋ 新規」**: 空のレイヤーグループを作ってこのメッシュにひも付け、テクスチャ元に設定します。
  - **「🖼 画像を読み込む…」／このスロットへ画像ファイルをドラッグ＆ドロップ**: 選択中メッシュの専用テクスチャ
    グループ（無ければ自動作成）へ、読み込んだ画像を**新規レイヤーとして**追加します。手持ちのテクスチャ
    画像を素早く取り込みたいときに便利です。
- **テクスチャ元（レイヤーグループ）**: 既定は「全体の合成」（ドキュメント全部を重ねた見た目）ですが、
  **レイヤーグループを選ぶと、そのグループの中身だけを合成した画像がこのメッシュの色になります**
  （Blender でマテリアルに画像を割り当てるのと同じ考え方）。例えば「肌」「服」「目」のようにレイヤーを
  グループ分けしておけば、パーツごとに別のメッシュ／マテリアルへ塗り分けられます。グループ内を塗ると
  自動的に反映されます（少し遅延あり）。
- ベース色（乗算）/ 粗さ / 金属度 / 発光色 / 発光の強さ
- ペイントテクスチャを表示 / 法線マップを表示 のトグル
- **クイック設定（Blender 風プリセット）**: プラスチック / マット・ゴム / 金属 / 光沢金属 / 発光 を1クリックで
- **コピー / 貼り付け**: 1 つのメッシュでマテリアルを作り、他のメッシュへそのままコピーできます
- 「リセット」「全メッシュに適用」

設定はメッシュごとに保持され、**プロジェクトに保存されます**（テクスチャ元のグループ指定も含む）。

## 14. ベイク（AO / 影 / 法線）

右ドックの**ベイク設定**パネル、またはベイクメニュー。

- **AO（アンビエントオクルージョン）** / **陰影（ライト）** / **オブジェクト空間法線** をテクスチャに焼き込み。
- **高 → 低 タンジェント法線ベイク**: 高ポリモデルを読み込んでケージ距離を指定して焼きます（CPU、1024² で数秒）。
- 解像度・品質はパネルで指定。AO / 影の遮蔽判定は深度マップ方式のため、薄い形状で軽微なリークが出ることがあります
  （品質「高」で軽減）。点光源 / スポットの影はベイク未反映（方向光のみ）。

## 15. アニメーション・アーマチュア・ライト

- **アーマチュア**: スキンメッシュ・ボーンをそのまま読み込み。右ドックの **アニメーション** パネルで
  **FBX / glTF に含まれるアニメーションクリップ**を一覧から選び、再生 / 一時停止 / タイムラインスクラブ /
  速度 / **ループ**、レストポーズ。**ポーズ中のメッシュにもペイント可**（スキニングを考慮したレイキャスト）。
  - **キーフレームに焼き込む（アニメ作成へ）**: 選択中のクリップを毎フレームサンプリングして
    「アニメ作成（キーフレーム）」のキー列に変換します（長さ・FPS もクリップに合わせます）。
    焼き込み後はモデルを元の姿勢へ戻すので表示は変わりません。取り込んだあとはキーを自由に編集できます。
  - **Unity ヒューマノイド .anim に変換…**: 選択中のクリップをサンプリングし、ボーン名を Unity ヒューマノイド
    スロットへ自動対応付けしたうえで `.anim`（YAML）を書き出します。対応表は「アニメ作成」→
    「ボーン対応表を開く」で確認・修正できます。
- **ボーン表示（Blender 風）**: 表示メニュー → ボーン表示、またはオブジェクトパネルの「ボーン表示」チェック。
  **なし / 八面体（Octahedral）/ スティック** から選べます。八面体は関節から子ボーンへ伸びる、
  Blender と同じ先細りのダイヤモンド形。選択中のボーンは色が変わります。
- **ポーズモード（FK）**: 右ドックの **ポーズ** パネル（ボーンのあるモデルを読み込むと出ます）で
  「ポーズモード（FK）」をオンにすると、**ボーンをクリックで選択 → ギズモで自由に動かせます**
  （ポーズモード中はペイントを止めます）。
  - **ギズモの種類**: 移動 / 回転 / 拡縮（ボタン、または **W / E / R** キー）。ボーンは回転だけでなく
    移動・拡縮も自由にできます
  - **バインドポーズに戻す** / **選択ボーンをリセット**
  - 作ったポーズに名前を付けて**複数保存**、クリックで適用（プロジェクトに保存されます）
  - **ポーズを書き出し… / 読み込み…** で `.p3dpose.json` としてやり取りできます

- **アニメ作成（キーフレーム）**: **アニメ作成** パネル（同じくボーンのあるモデルで表示）。
  1. **長さ（秒）** と **FPS** を決める
  2. ポーズを作り、タイムライン上の時刻で **「● キー追加」**（その時点の全ボーンの姿勢＝回転・移動・拡縮をキーに）
  3. 時刻を変えて別のポーズ → キー追加 …を繰り返す
  4. **▶ 再生 / ⏹ 停止 / ループ**。タイムラインのひし形マーカーをクリックでその時刻へ、`×` でキー削除
  - **「アニメモードにする」**: ポーズモード＋タイムライン＋自動キーを 1 クリックで有効化
  - **「自動キー」**: オンにすると、ボーンを動かすだけで**現在時刻にキーが打たれます**（Blender の自動キー相当）
  - **アニメを書き出し… / 読み込み…** で `.p3danim.json`。プロジェクト（`.p3dp`）にも保存されます
  - キーの間はスムーズに補間されます（回転はクォータニオン補間）

- **Unity へ書き出し（`.anim`）**: アニメ作成パネル下部。
  1. **「ボーン対応表を開く…」** → モデルのボーン名を Unity のヒューマノイド名（Hips / Spine / LeftUpperArm …）に
     対応付け。**「自動推測」** は Mixamo / Rigify / Unreal / Daz / MMD（日本語ボーン名）/ VRM などの命名に対応し、
     さらに**名前で分からないボーンは骨格の形（親子関係・左右・上下）から推定**します。
  2. **「Unity .anim を書き出し…」** で `.anim`（YAML）を出力。
  3. Unity 側: `.anim` をプロジェクトの `Assets` に入れ、対象モデルの **Rig を Generic**（または Humanoid＋Avatar）に
     設定して再生／リターゲットします。
  - 変換は**トランスフォームカーブ方式**の Generic クリップです（回転＝クォータニオン、ルートの移動）。
    Unity のマッスル（真のヒューマノイド）カーブは Unity 側のアバターソルバが必要なため対象外です。
- **ライト**: 環境光＋方向光 / 点光源 / スポットを追加・編集（色・強さ・方位／高度 or 位置・距離・スポット角・影）。
  「影を落とす」マスタートグル、`PCFSoftShadowMap`。
  - **選択モードでマウス操作**: モードチップで**選択モード**にすると、3D ビューにライトのハンドル（色付きの球）が
    表示されます。ハンドルをクリックで選択、ドラッグで動かせます。**点光源／スポットは位置（X/Y/Z）**、
    **方向光は原点からの向き（方位・高度）**をハンドル位置から計算します（方向光は原点へ伸びる線でレイ方向が
    見えます）。編集内容はライトパネルのスライダーにも即反映されます。

### Unity へ .anim を書き出す（Humanoid / マッスル値）

「キーフレーム・書き出し」パネルの **Unity へ書き出し** で形式を選べます。

- **ヒューマノイド（マッスル）**（標準）: Unity の Humanoid アニメーションと同じ **マッスル値**（95 本の
  マッスルカーブ＋ RootT / RootQ）で `.anim` を書き出します。Unity で Rig が **Humanoid** のアバターなら、
  **別のアバターにもそのまま**使えます（Animator Controller に入れるだけ）。
  - 「その場で再生（ルートモーションを焼き込む）」が ON だと、腰の前後左右の移動をポーズに焼き込みます
    （VRChat のロコモーションなどはこちら）。
  - 計算は Unity の Humanoid と同じ方式で、Unity 2022.3 で検証しています（体・手足は誤差 0.01 程度）。
    モデルは **T ポーズ**で作られたものを推奨します（Unity 側のアバター設定と同じ基準になるため）。
  - モデルに無い部位（あご・つま先など）はレストの値で出力されます。
- **このモデル専用**: ボーンの回転をそのまま記録する Generic の `.anim` です（ボーン対応表で名前を合わせます）。

「VRC ロコモーション」パネルの **Humanoid .anim でまとめて書き出し…** では、作成済みの全スロットを
マッスル値の `.anim` として一度に書き出せます（Unity のスクリプトなしで、そのまま他のアバターにも使えます）。

### アップデート

起動すると新しいバージョンがあるかを確認し、あれば **「新しいバージョンがあります」** という画面で
いまのバージョン → 新しいバージョンと変更内容を表示して、更新するかどうかを聞きます。

- **更新する**: 作業を続けたままバックグラウンドでダウンロードします。終わるとウィンドウ上部の **再起動して更新** で入れ替わります
  （押さなくても、インストーラー版は次に終了したときに更新されます）。アンインストールや再ダウンロードは不要です。
- **あとで**: 今回は更新しません（ウィンドウ上部の「更新する」からいつでも始められます）。次に起動したときにまた聞きます。
- **このバージョンをスキップ**: そのバージョンでは次から聞きません（さらに新しいバージョンが出たらまた聞きます）。

**ヘルプ ＞ バージョン情報…** で、いまのバージョン（インストーラー版 / ポータブル版）、最新版かどうか、配信元、
Electron などのバージョンを確認できます。スタート画面のタイトル横にもバージョンが出ます。
起動時の確認を止めるには、バージョン情報の「起動時に新しいバージョンを確認して、更新するか聞く」（または ヘルプ ＞ 起動時に自動で更新を確認）のチェックを外します。

### 透過テクスチャ（髪の毛先・まつ毛・レース・ガラスなど）

テクスチャの **透明な部分は 3D モデルでも透けて** 表示されます。マテリアル パネルの「透過（テクスチャのアルファ）」で方法を選べます。

- **自動**（既定）: メッシュの UV が乗っている所に透明な画素があれば透かします。はっきり抜けた穴は「切り抜き」、
  なめらかな半透明が多いと「半透明」になります。まだ何も塗っていない（全部透明な）メッシュは見えるように不透明のままです。
- **不透明** / **切り抜き**（しきい値で抜ける濃さを調整。髪・まつ毛・レース向き）/ **半透明**（ガラス・グラデーション向き）。
- 消しゴムで消した所や、透明な PNG を読み込んだ所もそのまま 3D に反映されます。トゥーン表示の輪郭線も切り抜きの形に沿います。

**モデルのテクスチャを取り込む**: モデルを開くと、同じフォルダ（または FBX フォルダの親）にあるテクスチャ画像を探し、
マテリアルごとに使う画像を名前から自動で選んだ割り当て画面が出ます（「Hair」→ Hair.png、「Cos」→ TEX Cos.png など。
マスク・法線・AO などの画像は候補から外れます）。必要なら選び直して「取り込む」を押すと、画像ごとのレイヤーグループになり、
各メッシュのマテリアルにひも付きます（同じ画像を使うマテリアルは 1 つのグループを共有し、どれを塗っても同じ絵に描かれます）。
「Hair_transparent」のような透過用マテリアルには **透過マスク**（白=見える・黒=透明。例: HairTransparent.png）も自動で選ばれ、
画像の透明度に掛け合わされます。あとからでも ファイル ＞ モデルのテクスチャを取り込む で開けます。
glb / VRM など、モデルに埋め込まれたテクスチャも選べます。

複数のマテリアルを持つメッシュは、読み込み時に **マテリアルごとのメッシュ**（例: Body → Body_Face / Body_Eye…）に分かれます。
マテリアルごとに別のテクスチャ・透過設定・表示切替ができます。

### 軽量表示（ノートパソコン・大きなモデル）

右下の「表示: 自動」で **自動 → 軽量 → 高画質** を切り替えられます。自動では 15 万ポリゴンを超えるモデルや
低スペックの PC で軽量表示になり、視点を動かしている間・塗っている間・アニメ再生中だけ解像度を下げて
影と選択枠を省略します（止めるとすぐ高画質に戻ります）。
FBX の **シェイプキー（表情など）は既定で読み込みません**。読み込みが数倍速くなりメモリも減ります
（塗りやアニメ作成には不要）。必要なら 環境設定 ＞ 一般 で読み込むようにできます。

### レイヤーの削除

レイヤーパネル上部の **削除**（ゴミ箱）、右クリック ＞ 削除、**Shift+Delete** でレイヤーやグループを削除できます。
グループは中身ごと消える前に確認が出ます。削除・新規・複製は **Ctrl+Z** で取り消せます。

### 腰 IK

アニメーションモードで **コントローラーを自動セットアップ** すると、腰に **緑の四角い輪（腰 IK）** が付きます。
腰 IK を動かす・回す（W 移動 / E 回転）と、**胸・首・頭はその場に残り**、背骨がその間で自然に曲がります。
手足も IK で止まったままなので、歩きの腰の揺れやひねり、片足重心のポーズが作りやすくなります。
体ごと動かしたいときは、これまでどおり外側の **白い輪（体全体）** を使います。
背骨は伸び縮みしないため、腰を大きく下げたり離したりすると、届かない分だけ胸も一緒に動きます。

### ロコモーションのサンプル・キーの数

アニメーション ツールの **モーションのひな形** の下に **ロコモーションのサンプル（歩き・走り）** があり、
待機・歩き（前 / 後 / 左 / 右）・走り・ダッシュ・しゃがみ・伏せ・空中・着地 の 1 周期をタイムラインに作れます
（VRChat 用のスロットとは別の、ふつうのアニメです。そのまま編集・Unity へ書き出しできます）。

- **キーの数**: 「主要ポーズだけ（歩きなら 1 周期 4 キー＋最後）／標準（8 キー）／細かめ（16 キー）／毎フレーム」から選べます。
  キーが少ないほど、ドープシートでタイミングをずらしたり、コントローラーでポーズを直したりしやすくなります。
  ひな形（手を振る など）にも同じ設定が効きます。VRC ロコモーション パネルにも同じ「キーの数」があります。
- **前へ進む（ルートモーション）**: OFF ならその場で足踏み（ループ向き）、ON なら実際に前や横へ進むクリップになります
  （速さは VRChat の移動速度をキャラクターの大きさに合わせたもの）。
- 歩幅・腕の振り・上下の揺れ・前傾・テンポ は VRC ロコモーション パネルのスライダーの値が使われます。

### 複数選択

アニメーションモード（ポーズ編集中）の 3D ビューで:

- **クリック**: そのコントローラー（またはボーン）だけを選択。**Shift+クリック** で選択に追加
  （もう一度 Shift+クリックで外す）。**Ctrl+クリック** で選択から外す。
- **空いている所をドラッグ**: 囲んだコントローラーをまとめて選択（Shift を押しながらで追加、Ctrl で除外）。
- **A** ですべて選択、**Alt+A** か **Esc**（または空いている所をクリック）で選択解除。

複数選ぶとギズモが選んだものの中心に出て、**W / E / R** で全部をまとめて移動・回転・拡縮できます
（例: 両足の IK をまとめて上げる、腕のリングをまとめてひねる）。選択中はオレンジ、最後に選んだもの（アクティブ）は薄い黄色です。

### ドープシート（キーを詳しく見る）

タイムラインの **ドープシート** ボタンで、Blender のドープシートのような表示に切り替わります（上の境目をドラッグで高さ調整）。

- 行: 「すべてのキー」「体の中心 / 左腕 / 右腕 / 指 / 脚 / その他」のグループ（▸ で開閉）と、その中のボーン。
  「動きのあるボーンだけ」で値が変わるボーンだけ、「選択中のみ」で 3D ビューで選んだコントローラーのボーンだけを表示。
- ◆ がキー。同じ値が続く所は帯（ホールド）で表示されます。選択中のキーはオレンジ。
- **クリック / Shift+クリック / 空いた所をドラッグで囲む** でキーを選択（ボーン名をクリックでその行のキーを全部選択）。
- 選んだキーを **ドラッグ** すると、フレーム単位で前後に移動（移動先のキーは置き換え）。**X / Delete** で削除、
  **Ctrl+C** でコピー → 再生位置で **Ctrl+V** で貼り付け、**A** で全選択、**Alt+A** で解除。
- 上の目盛りをクリック / ドラッグで再生位置を移動、キーをダブルクリックでその時刻へ。
- **Ctrl+ホイール** で拡大縮小、**Shift+ホイール** か中ボタンドラッグで左右に移動、ホイールで行をスクロール、**全体表示**（Home）。
- 下の欄に、選んだキーのボーン名・フレーム・回転（X/Y/Z 度）・位置が出ます。
- 操作はすべて **Ctrl+Z** で取り消せます。

### ミラー（左右対称）

アニメーション ツールの **左→右 / 右→左 / 反転（M）** の下で、ミラーする部位を選べます:
**腕（肩・腕・手）／指／脚（脚・足・つま先）／体の中心（腰・背骨・首・頭）**。チェックを外した部位はそのまま残ります
（例: 脚を外して 左→右 を押すと、腕だけ左右そろえて脚は別々のまま）。

**動かすと反対側も動く（ライブミラー）** を ON にすると、左右どちらかの手足（IK・FK コントローラーやボーン）を動かしている間、
チェックした部位は反対側も鏡写しで動きます。動かしている部位だけが対象なので、ほかの部位のポーズは崩れません。
設定は次回も保持されます。

### 元に戻す（アニメーション）

アニメーションモードでは **Ctrl+Z** で 1 つ前の操作に戻し、**Ctrl+Y / Ctrl+Shift+Z** でやり直せます
（キーの追加・削除・移動、コントローラーでのポーズ変更、ひな形の読み込み、反転・リセットなど。最大 100 手）。
ペイントモードではこれまでどおりペイントの取り消しになります。

### VRChat 用ロコモーション

アニメーションモードの左側にある **「VRC ロコモーション」** パネルで、VRChat のロコモーション（移動）用
アニメーションを一式まとめて作れます（ヒューマノイドのモデルが必要です）。

1. **全スロットをまとめて作成** — 待機・歩き（前後左右）・走り（前後左右）・ダッシュ・しゃがみ（待機＋前後左右）・
   伏せ（待機・前進）・空中・着地の 19 スロットを自動作成します。すべて**その場で動き**（腰が前後左右に流れない）、
   **ループのつなぎ目が一致**した状態で作られます。
   「歩幅・腕の振り・上下の揺れ・前傾・テンポ」のスライダーは次に作成するときに反映されます。
2. 各スロットの **編集** でタイムラインに読み込み、コントローラーで手直しして **K** でキーを上書きします。
   変更はそのスロットに自動で保存されます（黄色い印 = 手直しあり）。
   - **ループを閉じる**: 最後のキーを最初のキーとそろえて、ループのつなぎ目のガタつきを消します。
   - **その場に固定**: 腰の前後左右の移動を消します（上下の揺れは残ります）。
   - **反対側のスロットを左右反転で作成**: 「歩き 右」から「歩き 左」などを作ります。
     左右どちらかが未作成でも、書き出し先の Unity 側で反対側を反転して自動で補います。
   - **移動しながら再生（足すべり確認）**: 再生中、VRChat の移動速度でモデルを動かします。足が地面をすべって
     見える場合は「テンポ」や「歩幅」を調整して作り直してください。
3. **VRChat 用に書き出し…** — Unity プロジェクトの **Assets** フォルダを選ぶと、`PSD3DPaint_VRC` フォルダ
   （Unity 用スクリプトとクリップデータ）が作られます。
4. Unity でアバターの FBX の Rig を **Humanoid** にしておき、メニュー **Tools ＞ PSD 3D Paint ＞
   VRC ロコモーションを作成** を開き、シーン上のアバターを指定して **作成** を押します。
   - `PSD3DPaint_VRC/Generated/<アバター名>/` に Humanoid アニメーション（.anim）と
     `PSD3DPaint_Locomotion.controller` ができます。
   - コントローラーは VRChat の組み込みパラメータ（VelocityX / VelocityZ / Upright / Grounded など）で動きます。
     立ち・しゃがみ・伏せは 2D ブレンドツリー、Upright で切り替え、Grounded で空中 → 着地。
   - VRChat SDK が入っていれば、Avatar Descriptor の Playable Layers ＞ **Base** に自動で設定されます
     （Playable Layers が未初期化のときは、Inspector で一度「Customize」を押してから再実行）。

ロコモーションのクリップはプロジェクト（.p3dp）に保存され、自動保存・復元の対象にもなります。

## 16. プロジェクトの保存と読み込み

独自の `.p3dp` 形式（1 つの ZIP に `project.json` ＋ PNG 群）。

| 操作 | ショートカット |
| --- | --- |
| プロジェクトを開く | `Ctrl+O` |
| 上書き保存 | `Ctrl+S` |
| 名前を付けて保存 | `Ctrl+Shift+S` |

保存されるもの: 全レイヤー（ラスタ / グループ / マスク / 調整 / 編集可能なベクター）、法線ハイトマップ、
選択範囲、ブラシ設定、**埋め込んだ 3D モデル（元バイトごと）またはプリミティブ種別**、メッシュ別マテリアル、
ビュー状態（Z-up / シェーディング）。

- **未保存の変更があるまま閉じようとすると警告ダイアログ**（保存して閉じる／保存せずに閉じる／キャンセル）。
- 開いたプロジェクトは「最近開いたファイル」にも追加されます（最大 15 件）。

## 17. 書き出し

**ファイル**メニューから。

- **PSD を書き出す（`Ctrl+E`）**: レイヤー構造・不透明度・ブレンドを保持。Photoshop / Clip Studio でそのまま開けます。
- **PNG / JPEG / WebP を書き出す（統合）**
- **法線 PNG を書き出す**
- 画像を**レイヤーとして読み込む**（PNG / JPEG / WebP / BMP）。PSD の読み込みも可。

## 18. Python プラグイン

`plugins/*.py` を置くだけで**フィルターメニュー**に項目が増えます。

- `register(...)` でメニュー階層・パラメータを宣言。
- `psdpaint` SDK: `get_image / set_image`（RGBA、numpy 対応）、`layers / new_layer / set_layer / fill`、
  `bake('ao' / 'light' / 'objnormal')`、`message / progress / log`。
- パラメータがあれば自動ダイアログ、出力は Python コンソールパネルへ。編集は取り消し可能。
- **環境設定 → プラグイン**、またはフィルターメニューから **「ファイルから導入…」**で `.py` / `.zip` を取り込み、
  各プラグインを有効／無効切替、ユーザー導入分は削除可。Python 実行ファイルの場所も指定できます。
- 同梱例: 色を反転 / 明るさ・コントラスト / ガウスぼかし / AO をベイクして合成。
- **アドオンの作り方**は [docs/PLUGINS.md](docs/PLUGINS.md)、ひな形は [contrib/plugin-template/](contrib/plugin-template/)。
  作ったアドオンやテクスチャプリセットは [contrib/](contrib/) への PR で共有できます。

## 19. キーボードショートカット

環境設定 → ショートカットで**すべて再割り当て可能**です。以下は初期値。

### ファイル・編集

| キー | 動作 |
| --- | --- |
| Ctrl+N | 新規テクスチャ |

## 20. 環境設定

**編集 → 環境設定…（`Ctrl+,`）**。タブ式ダイアログ。設定は Windows のユーザーデータに保存されます。

- **一般**: 言語（日本語 / English）、既定キャンバス幅・高さ・背景、ブラシ既定値、3D ピクセル比上限、
  静止時 FPS、影、ベイク既定解像度、**元に戻す段数**、スタート画面の表示。
- **外観**: テーマ（Dark / Darker / Light / High Contrast / Custom）、アクセント色・背景色・パネル色、
  フォントサイズ（すべて即時反映）。
- **ショートカット**: 全操作の一覧。行をクリック → キー入力で再割り当て、`↺` で個別初期化、重複警告、Esc で取消。
- **プラグイン**: 上記「Python プラグイン」を参照。

## 21. 困ったとき（FAQ）

**Q. `.exe` を実行すると「WindowsによってPCが保護されました」と出る**
署名が無いための警告です。［詳細情報］→［実行］で起動します。配布元が信頼できる場合のみ実行してください。

**Q. 3D モデルが読み込めない / エラーが出る**
- `.gltf` は外部ファイル参照があると読めません。`.glb` で書き出すか、自己完結の `.gltf` にしてください。
- 読み込み失敗時は形式別のエラーがステータスバー／ダイアログに出ます。メッセージを確認してください。
- 一部だけ非対応（カメラ・ライト等）の場合は、その部分だけ「空オブジェクト」になり、残りは読み込まれます。

**Q. FBX で「Cannot read properties of undefined (reading 'curves')」**
壊れたアニメーションカーブが原因です。**アニメーションを捨ててジオメトリだけ**読み込む挙動になっているので、
モデル自体は表示されます。

**Q. モデルの位置がずれている / 見えない**
読み込み時に中心が原点へ来るよう自動配置されます。見当たらないときはテンキー `.` で全体表示してください。

**Q. UV が無いと言われて塗れない**
STL / PLY や、UV 展開されていないメッシュはペイントできません（表示のみ）。元ツールで UV 展開してから
`.glb` / `.fbx` などで書き出してください。

**Q. だんだん重くなる**
アンドゥ履歴のメモリは触れた範囲だけ・合計約 600 MB で頭打ちになるよう対策済みです。
それでも重い場合は、環境設定で「元に戻す段数」を下げる、キャンバス解像度を下げる、
静止時 FPS を下げる、影を切る、を試してください。

**Q. アプリのアイコンが古いまま（エクスプローラー表示）**
Windows のアイコンキャッシュが残っているだけです。別フォルダーへコピーし直すか、サインアウト／再起動で更新されます。

**Q. 設定を初期化したい**
`%APPDATA%\PSD 3D Paint\` を削除するとリセットされます（プロジェクトファイル `.p3dp` は別の場所なので消えません）。

## 22. 既知の制限

- コード署名なし（SmartScreen 警告が出る）。
- `.gltf` の外部参照は非対応。STL / PLY は表示のみ。glTF / FBX の元マテリアルはペイント用に置換。
- UV シーム・裏面へのブリード補正なし。マルチマテリアル / 複数 UV セットは 1 枚のテクスチャとして扱う。
- 3D ミラーは左右対称メッシュ前提。UV が左右反転共有のモデルは 2D ミラー向き。
- CMYK ソフトプルーフは ICC 非使用の近似。インデックスカラーは「モード」ではなく減色フィルター。
- グラデーション／テキスト／パスの凹凸（ノーマル）化は未対応（今後）。ケージ変形なし。
- 点光源 / スポットの影はベイク未反映（方向光のみ）。
- undo 対象はペイント操作のみ。レイヤー構造変更・ベイク・調整パラメータ・選択範囲の作成／変形は対象外。
